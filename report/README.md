# Test Reports

This directory contains sanitized Autobricks JWT test reports generated by:

```bash
./test/jwtd-test.sh
```

Each report filename contains the tested repository version and execution time.
The report-generation path removes credentials, encrypted token values, key
material, usernames, user and group identifiers, hostnames, private or
loopback network identifiers, ports, MAC addresses, absolute filesystem paths,
and test working paths before writing output. Report generation stops when the
redaction self-test or the output pipeline fails.

Only reports produced by the test script after a successful redaction self-test
belong in this directory. Raw terminal captures and unfiltered command output
must not be committed.
