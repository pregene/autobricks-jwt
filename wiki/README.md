# Autobricks JWT User Guide

This directory contains user-facing documentation for installing, configuring,
using, and operating Autobricks JWT.

Each guide describes one complete user task. A guide includes its prerequisites,
required inputs, procedure, expected result, applicable security boundary, and
recovery information when the operation can fail.

The repository root and `docs/` directory contain the normative architecture,
security, protocol, and lifecycle contracts. User guides in this directory
explain how to apply those contracts without redefining them.
